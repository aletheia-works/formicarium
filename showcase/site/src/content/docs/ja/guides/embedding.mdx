## 条件

- **同じ origin。** Worker（`runtime/web/package-worker.bundle.js`）と
  `assets/paludarium/` のコア（loader の `index.mjs`、その隣のモジュール、
  `paludarium.wasm`、`build-info.json`）を page と同じ origin から配ります。
  Worker・loader・wasm・ビルド情報の絶対 URL を `assets` に渡し、ほかのモジュールは
  loader の隣から読み込みます。
- **クロスオリジン分離。** COOP `same-origin` と COEP `require-corp` を送るか、
  静的な hosting では coi-serviceworker などの service worker を使います。
- **CSP。** 同じ origin の script と Worker、WebAssembly の compile を許します。
  たとえば `script-src 'self' 'wasm-unsafe-eval'; worker-src 'self';
  connect-src 'self'` です。`blob:` は要りません。コアは SHA-256 を照合した後に
  資産の URL から読み込むので、信頼できる origin から配ります。
- **guest。** 同じ origin の guest の file と、その SHA256 と `build-info.json`
  を書いた catalog（`GuestCatalog`）を使います。`install <tool>` はすべての bytes
  を確かめてから guest を登録します。

## 出力と表示

`CommandSession.execute` は command ごとに元の `stdout` と `stderr` の bytes を
返します。guest の実行では同じ bytes が `onOutput` でも少しずつ届くので、どちらか
一方だけを書きます。表示のときは bytes を文字に decode し、HTML として扱いません。
`onProgress` は全体の大きさが分からないとき `totalBytes: null` を返し、`0` とは
区別します。取り消すには `AbortSignal` を渡し、page を離れるときは session を
dispose します。
