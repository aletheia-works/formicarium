## 条件

- **同じ origin。** Worker（`runtime/web/package-worker.bundle.js`）と
  `assets/paludarium/` のコア（loader の `index.mjs`、その隣のモジュール、
  `paludarium.wasm`、`build-info.json`）を page と同じ origin から配ります。
  `assets` を渡さなければ、browser の entry は package の配置どおりに読み込みます
  （Worker は自分の隣、コアは package の `assets/paludarium/`）。
  origin の別の場所から配るときは、Worker・loader・wasm・ビルド情報の絶対 URL を
  `assets` に渡します。ほかのモジュールは loader の隣から読み込みます。
- **クロスオリジン分離。** COOP `same-origin` と COEP `require-corp` を送るか、
  静的な hosting では coi-serviceworker などの service worker を使います。
- **CSP。** 同じ origin の script と Worker、WebAssembly の compile を許します。
  たとえば `script-src 'self' 'wasm-unsafe-eval'; worker-src 'self';
  connect-src 'self'` です。`blob:` は要りません。コアは SHA-256 を照合した後に
  資産の URL から読み込むので、信頼できる origin から配ります。
  relay を通してゲストに network を渡す page は、relay の `wss:` の URL と、relay の token を
  取りに行く URL があればそれも `connect-src` で許します。showcase の端末が足すのは、token 関数の
  origin と `wss://*.lambda-microvm.ap-northeast-1.on.aws` だけです。
- **guest。** guest の HTTPS の URL と、その SHA256 と build info を書いた catalog
  （`GuestCatalog`）を使います。別の origin の guest には CORS が要ります。`install <tool>` はすべての bytes
  を確かめてから guest を登録します。
- **network。** ブラウザでは、ゲストは `network.relay` に渡した WebSocket の relay を通してだけ
  TCP の行き先につながります（[command API](/formicarium/ja/guides/command-api/)）。showcase は
  git と jj にだけ `network` を渡し、`allow: ['github.com:443']` と、Aletheia Works が AWS で動かす
  token 関数（サイトの `Origin` にだけ答える）から得た短い間だけ使える token の relay を付けます。
  Session はファイルを作るときにしか受け取らないので、curl が取り出した Mozilla の CA 証明書を、
  session を始めるときに home の下に置きます。

## 最初からツールを入れておく

ツールを導入済みの端末を開くには、command session を作る前に `createInstaller`
でツールを導入します。`install <tool>` と同じ確かめをしますが、何も書き出さない
ので、利用者には導入の行が見えません。導入したツールは、command session で名前を
打てば動き、どの guest の実行からも `/usr/bin/<tool>` として見えるので、ツールから
別のツールを起動できます（たとえば version control のツールが editor を開く）。
catalog の代わりに手元にある guest の bytes を登録するには、`validateGuest` で
確かめてから、その結果を `registerValidatedGuest` に渡します。

## 出力と表示

`CommandSession.execute` は command ごとに元の `stdout` と `stderr` の bytes を
返します。guest の実行では同じ bytes が `onOutput` でも少しずつ届くので、どちらか
一方だけを書きます。表示のときは bytes を文字に decode し、HTML として扱いません。
`onProgress` は全体の大きさが分からないとき `totalBytes: null` を返し、`0` とは
区別します。取り消すには `AbortSignal` を渡し、page を離れるときは session を
dispose します。
