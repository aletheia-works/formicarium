formicarium runs [paludarium](https://github.com/aletheia-works/paludarium),
a Rust counterpart of [blink](https://github.com/jart/blink), on WebAssembly: a
static x86-64 Linux executable starts without a kernel or a virtual machine,
and its system calls are answered inside the browser.

- **Runs in your browser.** The tools and their sample projects run in Web
  Workers in this tab. No server executes your commands.
- **Your data stays here.** Files you create live in the page's session and are
  gone when you reload. Only git and jj fetching from github.com (clone, fetch,
  pull) goes out, through Aletheia Works' relay.
- **Real binaries.** The showcase installs the latest stable aube, pitchfork,
  Biome, nano, jj and git that passed its Node, Chromium, Firefox, WebKit and Safari acceptance.

Open [the tools](/formicarium/tools/) to try a tool with a sample project, or
start from [an empty terminal](/formicarium/terminal/) and install one yourself.
The [guides](/formicarium/guides/getting-started/) explain how to embed the same
public API in your own page.
