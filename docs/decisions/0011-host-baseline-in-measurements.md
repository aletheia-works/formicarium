# 0011. 計測にホストの速さの基準値を添える

- 状態：採用（2026-10-05）
- 決めた人：ユーザー（条件をそろえた再計測を依頼）。記録の方法は開発が決めた

## Context（背景）

aube の計測値は、同じ条件でも 6〜9 秒と 17〜29 秒に分かれた。調べると、ホストの同じ固定計算の時間が最大 2.4 倍変動し、
aube の時間と連動していた（相関 0.6）。終了時の待ち、TLB の破棄、スレッドの空回り、wasm のコンパイラの段階は、原因ではなかった。

## Decision（決定）

`scripts/measure-aube.mjs` は、各試行の前後にホストの 1 スレッドの固定計算の時間を測り、`hostBenchMs` として記録する。
表には「ホスト基準」の列を出す。試行は 10 回を標準とする。

## Consequences（結果）

- ホストが遅い時間帯に当たった試行を見分けられる。
- 計測の時間が少し延びる（1 試行あたり数秒）。

## Alternatives Rejected（退けた案）

- **回数を増やすだけ**：ばらつきの原因が分からないままになる。
- **電源プランを高パフォーマンスに固定する**：利用者の環境の設定を変えることになる（今回はバランスのまま測った）。
