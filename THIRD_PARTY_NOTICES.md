# Third-party notices

The package contains the paludarium WebAssembly core and its JavaScript launcher, copied unchanged from the npm package `@aletheia-works/paludarium-wasm` into `assets/paludarium/`. The version is pinned in `assets/paludarium/build-info.json`, which also records the SHA-256 digest of every core file. No guest ELF, vendor source, or development dependency is included.
