# Summary

Keep the parent command's resolved workflow session when it spawns another engine command. A Codex thread can be accepted by the parent and then refused in its child if an older session remains mapped to a persistent host process.

Fixes #2266

## Changes

Use the existing hookChildEnv identity-pair contract in state unit routing, wave completion routing, and orchestrate child commands. The parent still validates its session through resolveWorkflowSelection. Add isolated root/helper-thread regressions and document the command boundary. Approval, artifact and source fingerprints are unchanged.

## User experience

Before: a valid current Codex chat can fail with a session override conflict in a child even though the parent selected the correct workflow.
After: the child keeps the same resolved chat, including a helper's root. A conflicting bare override is still rejected, and another chat's cursor record is untouched.
