# Summary

Code Generation summary confirmation must be recorded before its plan is generated, but the Plan Approval guard refuses that prerequisite while the plan is missing. Admit the existing confirmation-recording commands without granting Plan Approval.

Fixes #2265

## Changes

Extend the existing Code Generation `log decision` / `log answer` prerequisite branch to accept `summary-confirmation` alongside `plan-approval`. Keep command parsing, stage matching, log-owner validation, approval receipts and source fingerprints unchanged. Update the command matrices and add source-hook and compiled Codex-adapter regressions.

## User experience

Before: recording “Looks correct” is blocked because the plan it must precede does not exist. After: the confirmation is recorded and planning can continue. Source changes and developer dispatch still require Plan Approval, including after a valid summary receipt.
