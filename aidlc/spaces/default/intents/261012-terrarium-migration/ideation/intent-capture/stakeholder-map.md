# 関係者と判断権限

## Stakeholders
| 関係者 | 関心・役割 | Source |
|---|---|---|
| デモ閲覧者 | 移管後も3ツールのデモを利用できること | [Q2][Q3] |
| vivariumの再現利用者 | Biomeの再現結果が維持されること | [Q2][Q3] |
| 各リポジトリの保守者 | ビルド・検証の重複の削減と依存方向の整理 | [Q1][Q2] |
| 依頼者 | 今回の範囲・優先順位・公開の最終判断 | [Q2] |

## Decision Authority
今回の最終判断は依頼者が行い、追加の承認者はいない。利用者・保守者の関心を考慮するが、これらの役割へ承認権限を追加しない。[Q2]

定期報告や別の連絡先への通知は追加しない。[Q5]
