### Summary

主な問題は次の3点である。(1) U7 の実装を前提にした入力の扱いが具体化されておらず（catalog の相対 URL、pack・fixture の取得元、候補の照合）、そのままでは install が動かないか、実装者が推測する。(2) 端末の表示が公開 API の挙動と合わない（builtin の出力が出ない、表示 buffer の契約が無い）。(3) 合格証拠と配布の不変条件（受入した物と配布した物が同じであること、host の check の定義、出力 escape、NFR5 の直列化）を確かめる手段が決まっていない。Major が11件あるため NOT-READY とする。
